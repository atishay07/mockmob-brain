percentage of how well the task has been completed. You have been saying that it's 85% done to me since I don't know how many

**Why:** I had ended several passes with the same round figure ("about 85%"), which told him nothing and read as a habit.
His earlier working rule already says "never repeat an estimate without new evidence".

**How to apply:** Every status report carries a counted figure: write the list of what he asked (his items, numbered), mark
each done-and-verified, done-but-unverified, partly done or not done, and give done over total as the percent (count a
partly done or unverified item as half, and say so). Show the list or its counts beside the number. Never give a figure
that is not computed that way, and never the same figure twice unless the count really is the same. Lead with what was
actually built. Related: [[fewer-messages-only-what-matters]], [[visible-change-build-first]], [[build-features-before-audits]].
