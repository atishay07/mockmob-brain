## Lessons

- He judges a block by its presence. A correct, quiet component was rejected in one look; the large, branded one was approved
  in one look. Start bold.
- Edit `package.json` as JSON (a regex edit broke it, killed the dev server and blanked a visual check).
- A file the app shell also loads must not carry `mm-btn` classes (`css_split.test.mjs`): draw the key in the file's own sheet.
- The sticky room in the home desk grid slides over anything in a second grid row: new blocks go outside `.lp-desk`.
- Home section heights are only comparable on production, in the same browser, before and after (content-visibility).
- In Git Bash a lone `/` argument becomes a Windows path: prefix `MSYS_NO_PATHCONV=1` (a capture came back blank).
- Usage: five Opus lanes, one review and the orchestrator's own build took about 80% of a 5-hour window in 3 h 45 min.
